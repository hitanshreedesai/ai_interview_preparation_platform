# AI Interview Preparation Platform

A modern, full-stack, AI-powered interview preparation web platform designed specifically for college students and freshers to ace campus placements and technical interviews.

---

## 📁 Repository Overview

The platform code is organized as follows:

```
AI-Interview-Preparation-Platform/
├── frontend/     # React.js (Vite) frontend application
├── backend/      # Node.js + Express.js backend API
└── README.md     # Full documentation
```

For full details, installation instructions, API documentation, and architecture, please see:
👉 [AI-Interview-Preparation-Platform/README.md](./AI-Interview-Preparation-Platform/README.md)

---

## ⚡ Quick Start

### 1. Run the Backend API:
```bash
npm --prefix AI-Interview-Preparation-Platform/backend start
```
*API available at `http://localhost:5000/api`*

### 2. Run the Frontend Application:
```bash
npm --prefix AI-Interview-Preparation-Platform/frontend run dev
```
*Web App available at `http://localhost:3000`*

### 3. Run Integration Tests:
```bash
node AI-Interview-Preparation-Platform/backend/test_integration.js
```
